## Характер

Стиль — чистый, технологичный, продуктовый и очень читаемый. Он строится не на декоративности, а на:
- крупной типографике;
- ясной иерархии данных;
- большом количестве воздуха;
- округлых белых и голубых поверхностях;
- насыщенных синих акцентах;
- крупных продуктовых скриншотах;
- стеклянных/3D-иллюстрациях как одном сильном визуальном акценте.

Тени используются редко. Глубина создаётся цветом, мягкими градиентами, полупрозрачностью и масштабом объектов.

## Холст и поля

- Формат: **1920 × 1080 px**, 16:9.
- Базовое внешнее поле слева: **50–60 px**.
- Главный заголовок чаще начинается на **x ≈ 50 px, y ≈ 60 px**.
- Допустимые внутренние стартовые позиции для сложных композиций: 75–115 px.
- При плотной верстке использовать кратные блоки и стабильные колонки, а не случайные смещения.
- Крупную иллюстрацию можно обрезать краем слайда; это нормальная часть языка.

## Типографика

Единственное основное семейство — **Manrope**.

Используемые начертания:
- Regular — 400
- Medium — 500
- SemiBold — 600
- Bold — 700

### Базовая иерархия

| Роль | Параметры |
| --- | --- |
| Главный заголовок рабочего слайда | Manrope SemiBold, **73 px**, line-height 90–100% |
| Крупный альтернативный заголовок | Manrope SemiBold, **70 px** |
| Подзаголовок / крупная смысловая строка | 51–55 px |
| Заголовок карточки | 40–45 px, Medium/SemiBold |
| Основной текст | **35 px**, Regular/Medium |
| Плотный текст | 30–31 px, Regular |
| Комментарии / подписи | 24–26 px |
| Микротекст / метаданные | 20–22 px |
| KPI / крупные цифры | 65–104 px; при hero-подаче больше |
| Разделитель / hero-title | 120–200 px |

Типичные настройки:
- letter-spacing: **-2%** для большинства текстов;
- body line-height: 100–114%;
- крупные заголовки: плотный line-height 90–100%;
- избегать длинных строк на всю ширину слайда;
- цифры всегда должны читаться раньше поясняющего текста.

## Поверхности и карточки

На светлых слайдах:
- фон #ECF3FA;
- белые карточки без заметной обводки;
- типовой радиус **40 px** для крупных KPI-карточек;
- типовой радиус **20 px** для небольших информационных блоков;
- pills/chips — максимально округлённые;
- допустимы светло-голубые контейнеры и мягкие градиенты;
- тяжёлые drop-shadow не использовать.

На тёмных слайдах:
- глубокий синий/голубой линейный градиент;
- полупрозрачные синие glass-панели;
- белая типографика;
- cyan #00AAFF для KPI и акцентов;
- можно использовать мягкое внутреннее свечение вместо явной тени.

## Иллюстрации

Основной визуальный язык:
- 3D / фотореалистичные объекты;
- стекло, прозрачный пластик, металл;
- синие, голубые, фиолетовые световые оттенки;
- мягкое студийное освещение;
- аккуратное отражение и мягкая тень;
- чистый силуэт;
- прозрачный фон для отдельных ассетов.

Для спецтехники и запчастей:
- реалистичная техника без случайного брендинга;
- металл и пластик должны выглядеть физически правдоподобно;
- допускаются синие/фиолетовые рефлексы под окружение презентации;
- предмет может быть крупно обрезан краем слайда.

Для UI:
- реальные продуктовые скриншоты предпочтительнее стилизации;
- смартфоны ставить крупно, иногда группой по 3–4;
- не окружать каждый скрин отдельной декоративной карточкой без необходимости.

## Что делать

- Сначала строить иерархию: заголовок → ключевая цифра/мысль → доказательство.
- Давать одному изображению роль главного визуального якоря.
- Делать цифры крупными и легко сканируемыми.
- Использовать 2–3 крупных смысловых блока вместо множества мелких.
- Оставлять воздух вокруг заголовка и иллюстрации.
- Использовать асимметрию, если она усиливает смысл.

## Чего не делать

- Не использовать другой основной шрифт вместо Manrope.
- Не ставить тяжёлые тени под все карточки.
- Не делать тонкие декоративные рамки ради рамок.
- Не дробить контент на одинаковые мелкие карточки, если можно сделать сильную композицию.
- Не перегружать 3D-декором: один сильный объект лучше нескольких мелких.
- Не уменьшать цифры ради сохранения прежней сетки — сетка должна подчиняться смыслу.

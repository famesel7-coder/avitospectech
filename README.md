# Авито Спецтехника · система презентации

Текущая версия: **2.0, 23 октября 2026**.

## Канонический стиль

Для текущей презентации главным визуальным источником является Figma:
https://www.figma.com/design/YLrOv4c3BpgE27DoG4V5zQ/Untitled?node-id=0-1

Проанализированы все **53 слайда**. Рабочий формат — **1920 × 1080 px**.

Старый PDF «Дело спецтехники 2026» остаётся историческим референсом, но при конфликте правил **приоритет у текущего Figma-стиля**.

## Начало работы

1. Прочитать [визуальный стиль](brand/visual-style.md).
2. Выбрать [композиционный паттерн](brand/layouts.md).
3. Использовать значения из [design-tokens.json](tokens/design-tokens.json).
4. Для генерации нового слайда следовать [инструкции](prompts/slide-agent.md).
5. При необходимости свериться с [результатами Figma-аудита](analysis/figma-current-style.md).

## Коротко о системе

| Элемент | Текущее правило |
| --- | --- |
| Формат | 1920 × 1080, 16:9 |
| Шрифт | Manrope |
| Заголовок | SemiBold, обычно 73 px |
| Основной текст | Regular/Medium, обычно 35 px |
| Светлый фон | #ECF3FA |
| Основной текст | #1E1E1E |
| Основной синий | #5B89C6 |
| Яркий акцент | #00AAFF |
| Позитив | #64B76E |
| Ошибка / alert | #FF4053 |
| Внешнее поле | 50–60 px |
| Карточки | 20 px small / 40 px large radius |
| Тени | минимально; глубина через цвет/градиент/стекло |
| Визуал | крупные product screenshots + стеклянные/CGI 3D-акценты |

## Главный принцип

Сетка подчиняется смыслу. Не уменьшать ключевые цифры и не сохранять старую карточную структуру только потому, что она была в драфте. Новая верстка должна сначала давать читаемый вывод, затем доказательства и только потом декоративный визуал.

## Начало работы

1. Прочитать [визуальный стиль](brand/visual-style.md).
2. Прочитать [Figma foundations](brand/figma-foundations.md).
3. Выбрать [композиционный паттерн](brand/layouts.md).
4. Использовать значения из [design-tokens.json](tokens/design-tokens.json).
5. Для генерации нового слайда следовать [инструкции](prompts/slide-agent.md).
6. При спорном решении сверяться со страницей Figma **STYLE GUIDE · AVITO SP** и исходными референсными слайдами.

## Главный принцип

Сетка подчиняется смыслу. Не уменьшать ключевые цифры и не сохранять старую карточную структуру только потому, что она была в драфте. Новая верстка должна сначала давать читаемый вывод, затем доказательства и только потом декоративный визуал.

# Авито Спецтехника · Дело спецтехники 2026

Единая система оформления новых слайдов по пользовательскому драфту.
Версия 1.0, 22 сентября 2026. Основание: **25 страниц PDF** `Дело_спецтехники_2026_шаблон.pdf`.

## Начало работы

1. Прочитать [руководство по стилю](brand/visual-style.md).
2. Выбрать [макет](brand/layouts.md) и посмотреть соответствующий PNG в `reference/slides/`.
3. Взять параметры из [design-tokens.json](tokens/design-tokens.json).
4. Найти иллюстрации в [каталоге](assets/README.md).
5. Для создания слайда использовать [инструкцию](prompts/slide-agent.md).

## Основные решения

| Элемент | Правило |
| --- | --- |
| Формат | 16:9. PDF 960 × 540 pt. Рабочая сетка для изображений 1920 × 1080 px |
| Заголовок рабочего слайда | Manrope SemiBold, около 40 pt в масштабе исходного PDF |
| Подзаголовки карточек | Manrope Medium, подтверждённый размер 20,04 pt |
| Основной текст новых слайдов | Manrope Medium; размеры выбирать по выбранному макету |
| Фон | Тёмный диагональный градиент, характерные цвета #121C2B и #2D3B4A |
| Акцент | #0049FF и #00AAFF, градиентные заголовочные плашки |
| Панели | #2D3B4A, мягкие скругления, без заметной обводки |
| Визуал | Объёмная спецтехника, металлические рамки «авитжеты», иконки из исходной библиотеки |

## Содержимое

- `source/` — неизменённый исходный PDF.
- `brand/` — визуальные правила, типографика, макеты, ограничения анализа.
- `tokens/` — машиночитаемые цвета, размеры и координаты.
- `prompts/` — инструкция для подготовки новых слайдов.
- `reference/slides/` — все 25 слайдов в PNG 1920 × 1080.
- `reference/contact-sheets/` — обзор всей презентации.
- `assets/` — 517 ресурсов изображений, извлечённых из PDF, каталог и привязка к страницам.
- `analysis/` — данные о тексте, шрифтах, геометрии и градиентах.
- `scripts/extract_reference.py` — воспроизводимое извлечение исходных материалов.

## Границы точности

Проанализирован PDF. PPTX не удалось загрузить, он не исследован и не включён в репозиторий.
Часть текста в PDF представлена изображениями с масками. Для неё нельзя подтвердить исходное семейство шрифта, размер или параметры текстового блока.
Некоторые страницы называются «векторными», но иконки в этом PDF растровые. Извлечённые PNG не являются SVG.
Файлы полноценных шрифтов, мастер-слайды, анимация и исходные данные диаграмм отсутствуют.
Подтверждённые параметры отделены от оценок и решений для новых слайдов.

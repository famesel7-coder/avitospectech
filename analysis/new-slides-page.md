## Что было сделано

1. Удалены служебные метки «в дизайн».
2. Вся типографика переведена на локальные `AVITO /` text styles.
3. Верхняя зона каждого слайда приведена к общей иерархии:
   - category / quarter → небольшой синий kicker;
   - смысловой тезис → главный заголовок 70–73 px;
   - hero-слайды используют крупный hero style.
4. Заголовки привязаны к safe margin 60 px.
5. Нормализованы основные текстовые блоки, подписи и секционные заголовки.
6. Карточки приведены к фирменным поверхностям и радиусам 20/40 px.
7. KPI-слайды получили отдельную адаптацию:
   - hero-метрики сохраняются крупными;
   - компактные План / Факт / YoY используют уменьшенную иерархию;
   - label, value и unit разведены по вертикали;
   - плотные табличные строки уменьшены до body/card typography для читаемости.
8. Исправлены вложенные текстовые wrapper frames: двигается контейнер, а не локальная координата текста.
9. Проведена выборочная визуальная QA-проверка разных типов слайдов и общая структурная проверка всех 43 экранов.

## Канонический workflow

При дальнейшей работе с этой страницей:

1. Сначала читать `brand/visual-style.md`, `brand/figma-foundations.md`, `brand/layouts.md`, `tokens/design-tokens.json`.
2. Использовать Figma page **STYLE GUIDE · AVITO SP** (`2025:65`) как визуальный reference.
3. Страницу **«Новые слайды»** (`2027:65`) считать уже нормализованной и продолжать изменения поверх текущей версии.
4. Не возвращать старые шрифты, старые служебные плашки и исходную разрозненную верстку.

# Инструкция для генерации новых слайдов · Авито Спецтехника

## Обязательный repo-first workflow

Перед каждой новой задачей по этой презентации:

1. Сначала прочитать актуальные правила в репозитории `famesel7-coder/avitospectech`.
2. Канонические файлы: `brand/visual-style.md`, `brand/figma-foundations.md`, `brand/layouts.md`, `tokens/design-tokens.json`.
3. Затем обратиться к Figma page **STYLE GUIDE · AVITO SP** (page node `2025:65`).
4. Для цвета / spacing / radius использовать collection **AVITO / Presentation**.
5. Для текста использовать локальные text styles `AVITO /`.
6. Если repo и Figma расходятся, **репозиторий выигрывает**, после чего Figma foundations нужно синхронизировать с repo.

## Порядок создания слайда

1. Сначала определить главный смысл слайда одним предложением.
2. Найти один главный визуальный приоритет: число, вывод, продуктовый экран или иллюстрация.
3. Выбрать ближайший паттерн из `brand/layouts.md`.
4. Не копировать старую верстку драфта механически: переставлять цифры и блоки, если так лучше читается.
5. Проверить, что заголовок и цифры считываются раньше пояснений.
6. Только после этого добавлять декоративный 3D-объект.

## Обязательные параметры

- Canvas: 1920×1080.
- Font: Manrope.
- Default light background: #ECF3FA.
- Main text: #1E1E1E.
- Default slide title: Manrope SemiBold 73 px.
- Default body: Manrope Regular/Medium 35 px.
- Safe outer margin: 50–60 px.
- Card radius: 20 px small / 40 px large.
- Primary blue: #5B89C6.
- Bright accent: #00AAFF.
- Positive: #64B76E.
- Negative/alert: #FF4053.

## Визуальный язык

Иллюстрации должны выглядеть как часть продуктовой презентации Avito:
- реалистичные 3D/CGI объекты;
- чистые силуэты;
- стекло, металл, прозрачный пластик;
- холодные синие/голубые/фиолетовые рефлексы;
- мягкий свет, аккуратная тень и отражение;
- PNG на прозрачном фоне для отдельных ассетов;
- без лишнего текста внутри картинки.

Для грузовиков, спецтехники и запчастей сохранять правдоподобные материалы и пропорции.

## Контроль качества

Перед финалом проверить:
- нет ли текста меньше необходимого только ради сохранения сетки;
- нет ли 5–6 одинаковых карточек там, где можно сделать 2–3 сильных блока;
- не конкурирует ли иллюстрация с цифрой;
- достаточно ли воздуха вокруг заголовка;
- одинаковы ли радиусы и отступы у родственных карточек;
- нет ли тяжёлых теней, случайных градиентов и лишних обводок;
- соответствует ли композиция светлому или тёмному режиму из текущего Figma-референса.
